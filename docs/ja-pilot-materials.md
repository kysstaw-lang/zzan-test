# 일본인 파일럿 자료 초안 (0단계)

> 일본어 원문 + 한국어 번역. `{ }` 안은 매번 바꿔 넣는 부분, `【미정】`은 아직 정하지 않은 부분.
> 운영 시간: 토 12:00~20:00 맡기기 / ~21:00 찾기, 일 09:00~20:00 맡기기 / ~21:00 찾기

---

## 1. LINE 메시지

### 1-1. 예약 확정 메시지

```
{お名前}様

この度はお申し込みいただき、ありがとうございます！
ご予約が確定しましたので、ご案内いたします。

━━━━━━━━━━━━
📅 お預け：{11月15日(土) 14:00}
📅 お受け取り：{11月16日(日) 10:00}
🧳 お荷物：{スーツケース1個・紙袋1個}
📍 場所：東大門歴史文化公園駅 {【미정】}番出口 前
━━━━━━━━━━━━

【当日の流れ】
① 約束の時間に出口前でお待ちください。到着したらLINEでご連絡します。
② お荷物の写真を撮り、番号札をお渡しします。
③ お受け取りの際は番号札をご提示ください。

【お預かりできないもの】
現金・貴重品、パソコンなど高価な電子機器、食べ物、危険物、ペット
※パスポートや財布は必ずお手元にお持ちください。

【モニターのお願い】
今回は無料モニターとしてご利用いただけます。
その代わりに、ご利用後に
・Googleマップへのレビュー
・15分ほどの簡単なインタビュー（LINE通話または対面）
にご協力いただけると嬉しいです🙏

時間の変更やキャンセルは、前日22時までにこのLINEでお知らせください。
簡単な日本語で対応しますので、ゆっくり話していただけると助かります😊

当日お会いできるのを楽しみにしています！
```

> **번역:** 예약 확정 안내. 맡기는 날짜·시간, 찾는 날짜·시간, 짐 종류, 장소(출구 미정). 진행 순서(출구 앞 대기 → 사진 촬영·번호표 → 번호표 제시 후 반환). 맡길 수 없는 물건(현금·귀중품, 고가 전자기기, 음식, 위험물, 반려동물. 여권·지갑은 직접 소지). 무료 모니터 대신 구글 리뷰와 15분 인터뷰 부탁. 변경·취소는 전날 22시까지. "간단한 일본어로 대응하니 천천히 말씀해 주시면 감사하겠습니다."

### 1-3. 평일 자동응답 (근무 중)

```

平日の日中は返信が遅くなります。19時以降に順番にお返事しますので、少々お待ちください🙇

```

```
{12:00}以降でご都合のよい時間はございますか？
```

## 2. 이용 동의서 (お荷物お預かり同意書)

> 인수할 때 종이로 서명을 받거나 구글폼 체크박스로 받는다. **배상 관련 문구는 무료 운영이라도 꼭 넣고, 유료 전환 전에 전문가 검토를 받는다.** 고의·중대한 과실로 생긴 손해까지 면책하는 조항은 효력이 없을 수 있어서 그 부분은 빼 두었다.

```
お荷物お預かり同意書（無料モニター）

1. 本サービスは無料のモニター運営です。
2. 次の物はお預かりできません：現金・貴重品・パソコン等の高価な電子機器・
   食べ物・危険物・ペット。これらが含まれていた場合の損害については
   責任を負いかねます。
3. お預かり時にお荷物の外観を写真で記録します。お荷物の中身は確認しません。
4. 当方の故意または重大な過失によりお荷物が紛失・破損した場合は、
   お荷物1個につき{30万ウォン}を上限として補償します。
5. 番号札をお持ちの方にお荷物をお渡しします。番号札を紛失された場合は、
   写真と身分証で本人確認を行います。
6. 受け取り時間を過ぎてもご連絡がない場合、7日後に連絡し、
   30日を過ぎてもお受け取りがない場合は処分することがあります。
7. 個人情報（お名前・連絡先・お荷物の写真）はお預かり業務と
   ご連絡のためにのみ使用し、お受け取りから{30日}後に削除します。

上記に同意します。

日付：____年__月__日
お名前：________________
連絡先（LINE ID）：________________
お荷物の数：____個　　番号札：No.____
署名：________________
```

> **번역:**
> 1. 무료 모니터 운영입니다.
> 2. 맡길 수 없는 물건: 현금·귀중품, 고가 전자기기, 음식, 위험물, 반려동물. 이런 물건이 들어 있었을 때 생긴 손해는 책임지지 않습니다.
> 3. 맡길 때 짐 겉모습을 사진으로 기록합니다. 짐 안은 확인하지 않습니다.
> 4. 저희의 고의 또는 중대한 과실로 짐이 분실·파손되면 짐 1개당 30만 원까지 보상합니다.
> 5. 번호표를 가진 분께 짐을 드립니다. 번호표를 잃어버리면 사진과 신분증으로 본인을 확인합니다.
> 6. 찾는 시간이 지나도 연락이 없으면 7일 후 연락하고, 30일이 지나도 찾아가지 않으면 처분할 수 있습니다.
> 7. 개인정보(이름·연락처·짐 사진)는 보관 업무와 연락에만 쓰고, 짐을 찾은 뒤 30일 후 삭제합니다.

## 3. 인터뷰 질문지 (약 15분)

> LINE 통화 또는 반환할 때 대면으로 진행. 답변은 기록용 스프레드시트에 옮긴다.

**시작 인사**
```
本日はありがとうございました！15分ほど、いくつか質問させてください。
正直なご意見がとても参考になります。
```

| # | 일본어 질문 | 한국어 | 확인할 것 |
|---|---|---|---|
| 1 | 今回の旅行で、荷物のせいで困った瞬間はありましたか？ | 이번 여행에서 짐 때문에 곤란했던 순간이 있었나요? | 문제가 실제로 있는지 |
| 2 | どちらに泊まっていましたか？（ホテル・Airbnb・ゲストハウスなど） | 어디에 묵었나요? | 숙소 유형 |
| 3 | このサービスをどこで知りましたか？ | 이 서비스를 어디서 알았나요? | 유입 경로 |
| 4 | 他の荷物預かり（コインロッカーなど）を探しましたか？なぜ使わなかったですか？ | 다른 짐 보관(코인라커 등)을 찾아봤나요? 왜 안 썼나요? | 경쟁 대안 |
| 5 | もし有料だったら、今回の利用でいくらまでなら払いますか？ | 유료라면 이번 이용에 얼마까지 낼 건가요? | 지불 의사 (원/엔) |
| 6 | 宿泊先から空港まで荷物を届けるサービスがあったら使いたいですか？いくらまでなら払いますか？ | 숙소에서 공항까지 짐을 보내주는 서비스가 있으면 쓰고 싶나요? 얼마까지 낼 건가요? | 2단계 배송 수요 |
| 7 | 使ってみて、不便だったことや改善してほしいことはありますか？ | 써보니 불편했던 점이나 바라는 점이 있나요? | 개선점 |
| 8 | 友達に勧めたいと思いますか？ | 친구에게 추천하고 싶나요? | 추천 의향 |

**추가로 물어볼 말**
- `もう少し詳しく教えていただけますか？` (조금 더 자세히 말씀해 주실 수 있나요?)
- `それはなぜですか？` (그건 왜 그런가요?)
- `例えば、どんな時ですか？` (예를 들면 어떤 때인가요?)

**마무리 인사 + 리뷰 부탁**
```
ありがとうございました！とても参考になりました。
もしよろしければ、こちらからGoogleマップのレビューをお願いします🙏
{レビューURL}
残りの韓国旅行も楽しんでください！
```
